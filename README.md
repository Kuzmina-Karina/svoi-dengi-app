# Свои деньги

[Открыть приложение](https://kuzmina-karina.github.io/svoi-dengi-app/)

Приложение личного бюджета: расходы, аванс и зарплата, свои счета, накопления и прогноз с процентами.

Каждый пользователь ведёт собственный бюджет в своём браузере. Записи не отправляются на сервер и не синхронизируются между устройствами. При очистке данных сайта браузер удаляет бюджет. Локальная база и личные операции владельца в эту сборку не включены.

Здесь находятся готовые статические файлы сайта. Обновления собираются из приватных рабочих исходников командой `npm run build:pages`; содержимое папки `docs` переносится сюда. GitHub Pages использует ветку `main` и корневую папку `/ (root)`.

Уведомления и лицензии библиотек находятся в `THIRD_PARTY_LICENSES.md`.
